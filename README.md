# RL Arena

Платформа лиг и кубков по Rocket League: регистрация 1v1 и 2v2, жеребьёвка, группы, круговые лиги, сетка плей-офф с bye, подтверждение результатов обеими сторонами, споры, судьи, таблицы, призы, уведомления и админ-панель.

## Стек

- Next.js 15 (App Router, Server Actions), TypeScript
- Postgres (Neon) через `@neondatabase/serverless`
- Сессии: JWT в httpOnly cookie (`jose`), пароли `bcryptjs`
- Турнирный движок — чистый TypeScript в `src/lib/engine`, покрыт тестами (`npm test`)

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Строка подключения Neon Postgres (ставится интеграцией Neon в Vercel) |
| `AUTH_SECRET` | Случайная строка ≥ 32 символов для подписи сессий |
| `SUPERADMIN_EMAIL` | Email, который при регистрации получает роль супер-администратора |
| `CRON_SECRET` | Секрет для ежедневных напоминаний о матчах (`/api/cron/reminders`) |

Схема БД (`db/schema.sql`) применяется автоматически перед каждой сборкой (`npm run build`).

## Роли

- **Супер-администратор** — всё, включая роли пользователей и удаление соревнований
- **Администратор** — соревнования, участники, жеребьёвка, расписание, правила, призы, объявления
- **Судья** — споры, результаты, статусы и время матчей
- **Участник** — регистрация, отчёты о матчах; доступа к админке нет

## Жизненный цикл соревнования

Черновик → Регистрация → (Чек-ин) → Регистрация закрыта → Жеребьёвка (предпросмотр, можно перетянуть) → Публикация (блокировка) → Групповой этап / туры → Плей-офф (создаётся автоматически) → Завершено (призовые места назначаются автоматически).
